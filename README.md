# Materi: Array dan Object

Membuat program javascript untuk mendalami materi dan cara mengakses array dan object beserta kombinasinya.

## Latihan Soal

```javascript
console.log(we.are.the.best)
// Koda

console.log(hello.world)
// Hello World

console.log(obj.str[3][1][2].man[0].tech.academy)
// Tech Academy

console.log(my[0].favourite[3].fruit.is)
// Apple

console.log(num.first[1] + num.second[2])
// 32
```
